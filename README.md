# Project X

Project X — это Android-приложение, разработанное на языке **Kotlin** с использованием современных архитектурных подходов и компонентов Jetpack.

🔧 Используемые технологии

- **MVVM архитектура**
- **ViewModel**
- **LiveData**
- **Navigation Component**
- **Retrofit** — для сетевых запросов
- **RecyclerView** — для отображения списка данных
- **Пагинация** — реализация постраничной загрузки данных при прокрутке

✨ Возможности

- Получение и отображение данных с удалённого сервера
- Экран со списком элементов
- Переход на экран деталей при нажатии на элемент
- Обработка ошибок и отображение статуса загрузки
